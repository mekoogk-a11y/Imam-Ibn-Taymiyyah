# موسوعة شيخ الإسلام ابن تيمية (Ibn Taymiyyah Digital Encyclopedia)

> **تراثٌ علمي موثّق • معرفةٌ متاحة • بحثٌ أيسر**  
> *Documented Heritage • Accessible Knowledge • Better Research*

منصة علمية دولية تفاعلية متخصصة في توثيق وبحث وقراءة تراث شيخ الإسلام أحمد بن عبد الحليم بن عبد السلام ابن تيمية رحمه الله (661 - 728 هـ / 1263 - 1328 م).

---

## 📖 المبادئ العلمية الحاكمة (The Strict Scholarly Directives)

1. **الصرامة التوثيقية ومنع توليد النصوص الزائفة (Zero Hallucination Policy):**
   - يُحظر على محرك الذكاء الاصطناعي («مساعد الباحث») اختلاق أو توهم أي نصوص، فتاوى، عناوين كتب، أرقام مجلدات، صفحات، أحاديث، أو استشهادات علمية.
   - في حال عدم العثور على نص موثق في قاعدة البيانات المفهرسة، يُجيب النظام صراحةً:
     - بالعربية: **«لم يتم العثور على نص موثّق في المصادر المتاحة.»**
     - بالإنجليزية: **"No verified text was found in the available sources."**
2. **العزو الكامل:** كل نص مستخرج يُعرض مقترناً باسم الكتاب، رقم المجلد، رقم الصفحة، اسم المحقق، والناشر.

---

## 🏛️ الأقسام والوظائف الرئيسية (Main Sections)

1. **الرئيسية (Home)**: محرك بحث فوري، استكشاف المصنفات، إحصاءات التوثيق، ومسارات البحث العلمي.
2. **الكتب والمؤلفات (Books Library)**: فهرس شامل للمصنفات (مجموع الفتاوى، درء تعارض العقل والنقل، منهاج السنة، الواسطية، السياسة الشرعية...) مع تفاصيل الطبعات والتحقيقات والفهارس.
3. **قارئ الكتب الرقمي (Digital Reader)**: واجهة قراءة عربية احترافية، تدعم وضع الصفحة الواحدة والقراءة المتصلة، التحكم بحجم الخط، العرض، النسخ التوثيقي، والحواشي.
4. **البحث العلمي المتقدم (Advanced Full-Text Search)**: محرك معالجة لغوية عربية يعالج التشكيل والهمزات، مع التصفية بالمجلد والباب والموضوع.
5. **الفتاوى والمسائل (Fatwas Database)**: قاعدة بيانات موثقة للأسئلة والأجوبة المحققة.
6. **السيرة العلمية (Biography)**: فصول السيرة الموثقة بأمهات كتب التراجم (ابن كثير، ابن عبد الهادي، الذهبي، ابن رجب).
7. **الخط الزمني التفاعلي (Chronological Timeline)**: خط زمني تفاعلي من 661 هـ إلى 728 هـ مع إثبات الوقائع ومصادرها.
8. **شجرة الموضوعات (Topic Taxonomy)**: تبويب موضوعي هرمي يربط القضايا العقدية والفقهية والأصولية بنصوصها.
9. **العلماء والشخصيات (Teachers, Students & Scholars)**: سجل الشيوخ والتلاميذ والمؤرخين.
10. **شبكة المعرفة العلمية (Knowledge Graph)**: شبكة علاقات تفاعلية تربط الكتب والموضوعات والأعلام والأماكن.
11. **المقالات والدراسات المحكمة (Academic Studies)**: أبحاث أكاديمية معاصرة في مناهج التوثيق والاستدلال.
12. **المخطوطات والوثائق (Manuscripts Archive)**: فهرس المخطوطات المحفوظة بالمكتبات العالمية مع أرقام الحفظ واللوحات.
13. **المكتبة الصوتية (Audio Library)**: تسجيلات وقراءات صوتية للمتون والشروح العلمية.
14. **مساعد الباحث الذكي (AI Research Assistant)**: محرك RAG يستند حصرياً إلى نصوص قاعدة البيانات المحققة.
15. **مكتبتي والمفضلة (Personal Library)**: إدارة المفضلة، العلامات المرجعية، والتظليلات الملونة.
16. **لوحة الإشراف والمراجعة (Scholarly Review & Admin)**: لوحة تدقيق النصوص والمصادر ومراجعة الإحالات.

## 🛠️ البنية التقنية (Technology Stack)

- **الواجهة الأمامية (Frontend):** React 19, TypeScript, Tailwind CSS v4, Lucide Icons.
- **الخادم والواجهات (Backend):** Node.js / Express, TypeScript (tsx/esbuild).
- **الذكاء الاصطناعي (AI & RAG):** Google Gemini 2.5/3.8 مع حصر السياق بقاعدة النصوص المفهرسة.
- **قاعدة البيانات (Database Schema):** PostgreSQL مع فهارس البحث النصي Trigam.

## 🚀 التشغيل المحلي (Quick Start)

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. إعداد متغيرات البيئة
cp .env.example .env

# 3. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
